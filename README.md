# Number Guessing Git Assignment

## Starting Branch Structure

- main: stable production branch
- dev: integration branch
- feature1: feature branch merged using merge
- feature2: feature branch updated with rebase
- feature3: feature branch that will be squashed
- hotfix: urgent production fix branch

## Branch Overview

feature1 contains game improvements merged from dev.

feature2 demonstrates rebasing to keep history linear.

feature3 contains multiple development commits that will be put  into one cleaner commit.

hotfix contains a fix that will be put into main.
